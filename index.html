RITE: Robust Iterative Task-Equivalent Latent Correction for End-to-End Driving under Visual Degradation

Figures BibTeX Paper (coming soon) Code (coming soon)

In brief: RITE learns where, how, and how far to correct degraded planning tokens, improving robust trajectory planning while limiting latent intervention.

RITE method overview

Abstract

Visual degradation perturbs the latent representations of end-to-end driving models, but representation error is not the same as planning risk.

RITE (Robust Iterative Task-Equivalent Latent Correction) decomposes latent recovery into three connected decisions: where to intervene, how the iterative path should evolve, and where the correction should end. It learns selective token gating from counterfactual planning regret, supervises a four-step refinement path, and uses the frozen planner’s local Jacobian to construct a minimum-norm task-equivalent endpoint.

Across nuScenes and NAVSIM v2, RITE improves planning under severe mixed visual corruption while controlling the magnitude of latent intervention. Training-only clean features, ground-truth trajectories, and Jacobians are removed from the deployment path.

Method

Where, how, and how far to correct

RITE inserts a lightweight correction module before a frozen planner. Its three components constrain a different part of the intervention.

01WHERE

Counterfactual planning regret

CPRG estimates which latent tokens would reduce planning loss if moved toward their paired clean counterparts.

rᵢ ≈ [−⟨∇L, zᶜᵢ − zᵒᵢ⟩]₊
02PATH

Planning-consistent refinement

PCRR unfolds the deployed four-step correction and supervises intermediate states and adjacent planning-loss changes.

z⁽⁰⁾ → z⁽¹⁾ → z⁽²⁾ → z⁽³⁾ → z⁽⁴⁾
03ENDPOINT

Minimum-norm task equivalence

MTEC finds a low-energy latent correction that locally reproduces the clean branch’s trajectory change.

δ* = Jᵀ(JJᵀ + μI)⁻¹Δτ
Execution contract

Rich supervision at training.
Lean correction at inference.

Training only

Teacher construction

Paired clean tokens, ground-truth future trajectories, planning gradients, and a 12-row local Jacobian provide regret and endpoint targets.

Deployment

Four-step forward path

Current observations and the action-conditioned temporal prior produce one shared token gate and four bounded residual updates.

Optimization scope

Base planner stays frozen

The visual encoder, query aggregator, latent world model, and planning head are fixed; only the regret estimator and refiner are learned.

Evaluation protocol

Conclusion

Task-equivalent recovery

RITE searches for a correction that is planning-effective, path-consistent, and small in latent space. It adds 0.821M parameters—2.14% over LAW—and removes all training-time teacher construction from inference.

Current limitation

The method still relies on a reliable temporal prior. Shuffled-prior tests expose this failure mode and motivate future correction-rejection mechanisms.
